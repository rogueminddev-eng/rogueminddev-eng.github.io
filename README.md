# NexDex

Public website: https://rogueminddev-eng.github.io/

This repository publishes the compiled NexDex website. `site.zip` contains only browser-ready HTML, CSS, JavaScript, optimized public images and source-linked price-history snapshots. The GitHub Actions workflow extracts and publishes that package to GitHub Pages.

Application source code, environment files, API keys and the private SQLite database are not included.

The catalogue is still being completed. Unverified prices and specifications remain labelled. Prices and history are dated records, not a live stock or price feed. Product data updates require a new locally built package.

The footer shows an approximate site-visit counter powered by Hits. Repeat visits and automated requests may count; this is not a unique-person count. See the website privacy page for details.
